================================================================================
MOBILE RESPONSIVENESS & ZERO-DISTORTION VIEW ARCHITECTURE
================================================================================

1. MOBILE NAVIGATION & DRAWER SYSTEM
   - Replaced fixed desktop-only horizontal navigation bar with an adaptive design.
   - Added interactive Mobile Hamburger Button (Lucide Menu / X icon) for screen widths <= 768px.
   - Implemented smooth dropdown/drawer transition with automatic body scroll locking (`overflow: hidden`) during menu open state.

2. FLUID & CLAMP TYPOGRAPHY
   - Standardized page header and title typography using CSS `clamp()` functions:
     `font-size: clamp(2.1rem, 6vw, 2.85rem)`
   - Prevents title clipping, line overflow, or layout breakages on narrow mobile screens (320px - 480px).

3. ADAPTIVE FLEX & GRID LAYOUTS
   - Replaced fixed 2-column grids (`1fr 220px`) in Projects and Blogs lists with responsive CSS grid auto-fit patterns (`repeat(auto-fit, minmax(260px, 1fr))`).
   - Action buttons (`View Resume`, `Explore Projects`, `Contact`) adaptively stretch to full width on mobile viewports for enhanced thumb-reachability.
   - Metric counters (LeetCode, Codeforces, Projects, Stack) transition cleanly into a 2x2 mobile grid.
